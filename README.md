# Amatsukiyora — Cognitive Universe

Запуск Windows: распаковать проект, установить Python 3.10+ с SQLite, запустить `start.bat`. Node.js для обычного запуска не нужен.

Единая SVG-карта объединяет кластеры памяти, реальные связи, документы и внешнюю статистику. Выберите категорию или кластер для перехода к отдельным записям. Страницы содержат до 80 элементов; общая статистика не ограничена размером страницы. Колесо мыши приближает к курсору, перетаскивание перемещает карту, 1:1 сбрасывает вид.

Файлы поместите в `Aspksa/Документы` внутри проекта. При запуске и по кнопке «Обновить» каталог сканируется. TXT/MD/CSV/JSON/LOG: индексируется до первых 128 КиБ в UTF-8. PDF/DOCX/XLSX/PPTX/RTF/ODT/HTML: пока только метаданные. Удалённые файлы скрываются, их идентификаторы и связи сохраняются. Каталог и SQLite исключены из Git.

API: GET /api/universe, GET /api/universe/page?group=..., GET /api/universe/search?q=... (буквальный поиск по индексированному тексту). Существующие API памяти и связей сохранены; POST /api/universe/document-link принимает document и memory, только с локального origin. Связи не создаются из случайных совпадений. Общие маршруты агрегируют существующие связи; линии от ядра к группам обозначают структуру категорий.

Ограничения: нет автоматического извлечения фактов, семантического поиска, RAG, оценки достоверности и моделирования сознания. Тесты проверяют 5000 записей и 1000 файлов на уровне SQLite/API-функций; это не браузерный FPS-бенчмарк. Старые модули двух карт сохранены в репозитории, но не загружаются на главной.

Без Canvas/WebGL, Docker, внешних библиотек и платных вызовов. Новый модуль SVG использует JSDoc с проверкой TypeScript.
